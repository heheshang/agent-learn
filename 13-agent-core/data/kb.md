# Agent 核心概念知识库

本文件是 `13-agent-core` 的检索工具（`search`）背后的知识库。
Agent 通过 `search` 工具从这里召回片段，就像 LangChain 官方 ReAct 示例里的
`Wikipedia` 工具一样 —— 只是把「维基百科」换成了「本地知识库」。

## ReAct 框架

ReAct（**Re**asoning + **Act**ing，Yao et al. 2023, arXiv:2210.03629）把
「推理」和「行动」交织在一起，让语言模型交替产出思考轨迹与环境交互。

ReAct 的核心循环由四个动作标记组成：

- `Thought:` —— 模型当前的思考，说明下一步为什么要这么做。
- `Action:` —— 要调用的工具名。
- `Action Input:` —— 传给该工具的参数。
- `Observation:` —— 工具执行后返回给模型的结果。

循环反复进行，直到模型输出 `Final Answer:` 为止。ReAct 把动作空间从
「只有语言」扩展到「语言 + 任务相关的离散动作」，因此模型既能规划又能
与外部世界交互，从而缓解纯思维链（CoT）容易产生的幻觉和错误传播。

论文在 HotpotQA、FEVER 等知识密集型任务和 ALFWorld、WebShop 等交互式
决策任务上都验证了：带 `Thought:` 的 ReAct 明显优于去掉 `Thought:` 的
纯 Act 基线。

## Agent 的三大组件

一个以大语言模型为大脑的自主 Agent 系统，通常由三个组件构成。

### 规划（Planning）

复杂任务往往包含很多步骤，Agent 必须知道它们是什么并提前规划。

- **任务分解**：把大任务拆成更小、可管理的子目标。常用手段是思维链
  （Chain of Thought）、思维树（Tree of Thoughts）。
- **自我反思（Self-Reflection）**：对过去的行为做自我批评和反思，
  从错误中学习并精炼后续步骤。ReAct 本身就是把推理与行动交织的一种
  反思机制。

### 记忆（Memory）

- **短期记忆**：上下文窗口内的信息，也就是「in-context learning」。
- **长期记忆**：外部向量库，检索时快速召回，海量历史信息可长期保留。

人类记忆的三类（感觉记忆、短期记忆、长期记忆）可以近似映射为：
感觉记忆对应原始输入的嵌入表示，短期记忆对应上下文学习，
长期记忆对应外部向量库。

### 工具使用（Tool Use）

工具使用是人类区别于其它物种的标志性能力。模型通过调用外部 API
获取权重里没有的信息：实时信息、代码执行能力、私有数据源等。

MRKL 论文里还有一个重要发现：大语言模型（7B）**很难可靠地提取出
算术运算的正确参数** —— 口头表述的算术题比写明式的算术题难得多。
所以「把算数交给工具」不是锦上添花，是必要的。

### MRKL 系统

MRKL 系统把大语言模型当成**路由器**，把请求分发给「专家模块」——
这些模块可以是神经网络模型，也可以是符号工具（计算器、汇率换算器、
天气 API）。实验表明，当外部符号工具足够可靠时，
「知道何时以及如何使用工具」比工具本身更关键。

## 规划与记忆的进阶方案

- **Reflexion**（Shinn et al. 2023）：给 Agent 配上动态记忆与自我反思，
  用二元的成功/失败奖励驱动，重试时把反思写进工作记忆。
- **思维链回溯（Chain of Hindsight, CoH）**：把一串带反馈的历史输出
  显式呈现给模型，训练出增量改进的能力。
- **算法蒸馏（Algorithm Distillation, Laskin et al. 2023）**：把跨回合的
  学习历史拼进上下文，让模型学会「算法」而不是单个任务的策略。

## 检索增强生成与 Agent 的关系

检索增强生成（RAG）解决的是「模型知识有截止日期」以及「私域知识」的问题，
Agent 解决的是「多步任务需要规划、试错与反思」的问题。

两者的接口就是**工具**：把检索包装成一个工具（`search`），Agent 就能
自己决定什么时候检索、用什么关键词检索、检索几次。检索从「固定流水线
的一环」变成「模型可调用的动作」，这是从 RAG 走向 Agent 的关键一步。

## 长上下文与外部记忆

上下文窗口是有限的，这限制了历史信息、详细指令、API 调用上下文和响应
的容纳量。外部向量库可以提供更大的知识池，但它的表示能力不如完整注意力。

在 Generative Agents（Park et al. 2023）里，长期记忆是一个记录自然语言
观察的**记忆流**，检索时同时考虑三个信号：

- **新近性（recency）**：最近发生的事件得分更高。
- **重要性（importance）**：区分平淡事件与核心记忆。
- **相关性（relevance）**：与当前情境或查询的关联程度。

## 工具调用的可靠性问题

自然语言作为模型与外部组件之间的接口，可靠性有限：模型可能输出格式错误，
偶尔会「反抗」指令。因此几乎所有 Agent 演示代码的一半工作量都花在
**解析模型输出**上 —— 这是工程上的真实成本，不是示例的附属品。
